# Security

Smog Shield has no accounts and stores nothing about users on the server. The assets worth protecting are the Gemini API key and quota, the honesty of the advice (no fake numbers, no hijacked prompts), and the visitor's browser.

## Known limits

- Rate limits and caches live in memory per server instance (see [docs/DECISIONS.md #8](docs/DECISIONS.md#8-in-memory-caches-and-rate-limits)). A determined attacker spread across many IPs or instances can exceed them; a shared store would fix that at scale.
- Requests without browser fetch metadata (for example `curl`) pass the cross-site check by design. They are still rate limited and body-capped.
- `style-src` keeps `'unsafe-inline'` because React `style` props are inline style attributes that a nonce cannot cover. Scripts are not affected.
- Advice is general public-health guidance, not medical advice.

## Reporting a problem

Please do not open a public issue for a security problem. Use GitHub's private vulnerability reporting on [Sarcastic-Soul/smog-shield](https://github.com/Sarcastic-Soul/smog-shield/security/advisories/new) and include:

- what you found and where (URL, file or endpoint),
- steps to reproduce,
- what an attacker could do with it.

You should get a reply within a few days. Please give us time to fix it before sharing details.
